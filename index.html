طريقة ترجمة فيديوهات كورسيرا إلى العربية

إذا كانت المحاضرة لا توفر ترجمة عربية مناسبة، يمكنك استخدام Lingo، وهي إضافة مستقلة ومفتوحة المصدر لمتصفح Chrome. تحتاج إلى مسار ترجمة إنجليزي متاح ومدعوم؛ لا تقوم الإضافة بتنزيل الفيديو أو تفريغ الصوت.

  1. نزّل مستودع Coursera Lingo وفك ضغطه.
  2. افتح chrome://extensions وفعّل وضع المطور.
  3. اختر Load unpacked ثم مجلد extension/ الذي يحتوي على manifest.json.
  4. افتح محاضرة كورسيرا تحتوي على ترجمة إنجليزية واضغط قراءة النص الأصلي.
  5. صدّر طلب الترجمة إلى ChatGPT واطلب ملف JSON مع الحفاظ على جميع معرفات id.
  6. استورد الترجمة من الإضافة لعرضها بالتزامن مع الفيديو.

يدعم الوضع اليدوي أيضًا استيراد VTT وSRT وتصدير VTT. إذا كانت المحاضرة طويلة، قسّم طلب الترجمة مع الحفاظ على المعرفات ثم اجمع النتائج قبل الاستيراد.

ترجمة كورسيرا تلقائيًا باستخدام ChatGPT Plus بدون API Key

صُمم الوضع التلقائي للربط مع اشتراك ChatGPT Plus أو Pro مؤهل دون إنشاء مفتاح OpenAI API شخصي أو إعداد فوترة API منفصلة. يلزم مساعد محلي مكتمل وNode.js 22 أو أحدث.

  1. ثبّت Node.js وشغّل START.cmd على Windows.
  2. أدخل مفتاح الاتصال المحلي الذي يعرضه المساعد في إعدادات الإضافة.
  3. اختر Continue with ChatGPT وأكمل تسجيل الدخول والموافقة عبر موقع OpenAI.
  4. حمّل الترجمة الإنجليزية واختر نموذجًا متاحًا وابدأ الترجمة.

تنبيه: الربط التلقائي تجريبي ويحتاج إلى التحقق من عمل المساعد وتسجيل الدخول والترجمة. يخضع لحدود استخدام الاشتراك، ولا يضمن ترجمة غير محدودة. الوضع اليدوي لا يحتاج إلى المساعد المحلي.

هل يمكن ترجمة محاضرات كورسيرا باستخدام ChatGPT؟

نعم، يمكن تصدير النص الإنجليزي المتاح إلى ChatGPT وترجمة المقاطع إلى العربية ثم استيرادها في Lingo لعرض النص المتزامن.

هل أحتاج إلى مفتاح API؟

لا يحتاج الوضع اليدوي إلى مفتاح API. الوضع التلقائي مصمم لاستخدام اشتراك مؤهل ومساعد محلي دون مفتاح OpenAI API شخصي، وهو تجريبي.

هل الإضافة مجانية؟

الإضافة مفتوحة المصدر وفق ترخيص MIT. أما الاشتراك المؤهل لخدمة الترجمة التلقائية فليس مجانيًا بالضرورة.

هل يمكن ترجمة فيديو بلا نص إنجليزي؟

لا، تحتاج النسخة الحالية إلى نص ترجمة إنجليزي متاح ومدعوم، ولا تشمل التعرف على الصوت أو الدبلجة.

هل يمكن إظهار النص العربي والإنجليزي معًا؟

نعم، صُممت Lingo لعرض النصين بالتزامن مع المحاضرة، مع التحكم بحجم الخط وموضعه.
